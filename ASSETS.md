# MemeSplice artwork

Two original static sprite atlases were created with the built-in image generation tool. No image generation service is connected to the application.

- `public/images/parents.png`: 1448 × 1086 pixels; 4 columns × 3 rows.
- `public/images/offspring.png`: 2172 × 724 pixels; 3 columns × 1 row.
- `public/images/prompts.json`: exact generation prompts and source metadata.

The `Artwork` component displays an individual portrait using CSS background positioning. The default Doge × Pepe pairing has three curated illustrations. Other mock pairings reuse the three offspring archetypes with a subtle hue variation; their names, lore, and inherited traits reflect their selected parents. Explore uses illustrative mock portraits.

Fonts are bundled in `public/fonts` and served locally: Space Grotesk and Inter, from Google Fonts. Coin portraits are illustrative reinterpretations, not official token logos.

The comparison order is balanced blend (atlas cell 1), Parent A dominant (cell 0), and Parent B dominant (cell 2). The three illustrations, names, tickers, taglines, lore, personalities, and inherited-trait explanations differ within each splice.
